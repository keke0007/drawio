## 练习1：文件批量操作

### 任务
创建文件批量操作脚本：
1. 批量重命名文件（添加前缀、后缀、序号）
2. 批量移动文件到指定目录
3. 批量删除符合条件的文件
4. 批量复制文件

### 要求
- 支持多种批量操作
- 安全确认机制
- 操作日志记录
- 错误处理

### 数据文件
- 使用 `data/files/` 目录下的测试文件
