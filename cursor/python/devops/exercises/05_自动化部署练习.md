## 练习1：Git操作自动化

### 任务
创建Git操作自动化脚本：
1. 自动拉取代码
2. 检查代码更新
3. 切换分支
4. 查看提交历史

### 要求
- 使用GitPython库
- 错误处理
- 日志记录
- 支持多种Git操作

### 数据文件
- 配置文件: `configs/git_config.json`
- 日志: `output/git_operations.log`
