# Python 自动化运维 - 进程管理练习

## 练习1：进程信息获取

### 任务
创建进程信息获取脚本：
1. 列出所有运行中的进程
2. 显示进程的详细信息（PID、名称、CPU、内存）
3. 按资源使用排序
4. 输出到CSV文件

### 要求
- 使用psutil获取进程信息
- 格式化输出
- 数据持久化
- 跨平台支持

### 数据文件
- 输出到 `output/process_list.csv`
