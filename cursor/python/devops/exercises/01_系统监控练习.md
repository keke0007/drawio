# Python 自动化运维 - 系统监控练习

## 练习1：系统信息获取

### 任务
使用`psutil`库创建一个系统信息收集脚本：
1. 获取CPU信息（核心数、使用率、频率）
2. 获取内存信息（总量、使用量、使用率）
3. 获取磁盘信息（总容量、使用量、使用率）
4. 获取网络信息（发送/接收字节数、包数）
5. 将信息保存到JSON文件

### 要求
- 安装psutil: `pip install psutil`
- 格式化输出系统信息
- 保存到 `output/system_info.json`

### 数据文件
- 使用系统实时数据

---

4. 生成CPU使用率趋势图

### 要求

- 使用matplotlib生成图表
- 运行时间可配置

### 数据文件
- 输出到 `output/cpu_monitor.csv`
- 图表保存到 `output/cpu_usage.png`

## 练习10：监控告警系统

### 任务
创建一个完整的监控告警系统：
1. 监控多个系统指标
2. 配置告警规则（阈值、持续时间）
3. 多种告警方式：
   - 控制台输出
   - 日志文件
   - 邮件通知（可选）
   - 钉钉/企业微信（可选）
4. 告警历史记录

### 要求
- 告警规则配置化
- 告警去重和聚合
- 告警级别（警告、严重、紧急）
- 告警恢复通知

### 数据文件
- 配置文件: `configs/alert_rules.json`
- 告警日志: `output/alert_log.txt`
- 告警历史: `output/alert_history.json`
