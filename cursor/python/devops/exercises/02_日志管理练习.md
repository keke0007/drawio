# Python 自动化运维 - 日志管理练习

## 练习1：日志文件读取和解析

### 任务
创建一个日志读取和解析脚本：
1. 读取 `data/access.log` 文件
2. 解析日志格式（IP、时间、方法、路径、状态码）
3. 统计访问次数
4. 输出统计结果

### 要求
- 使用正则表达式解析日志
- 处理不同格式的日志行
- 错误处理（无效日志行）
- 输出格式化

### 数据文件
- `data/access.log` - Web访问日志
- `data/error.log` - 错误日志
