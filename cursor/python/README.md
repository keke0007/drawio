## 🚀 快速开始

### 1. 环境准备

确保已安装Python 3.7或更高版本：

```bash
python --version
```

### 2. 安装依赖

对于基础练习，只需要Python标准库。对于数据处理练习，需要安装：

```bash
pip install numpy pandas matplotlib seaborn
```

### 3. 学习路径

建议按照以下顺序学习：

1. **基础语法** (`exercises/01_基础语法练习.md`)
   - 变量和数据类型
   - 控制结构
   - 字符串处理
   - 列表、字典、集合操作

2. **函数和模块** (`exercises/02_函数和模块练习.md`)
   - 函数定义和使用
   - 参数类型
   - 模块导入
   - 标准库使用

3. **面向对象编程** (`exercises/03_面向对象编程练习.md`)
   - 类和对象
   - 继承和多态
   - 封装
   - 特殊方法

4. **文件操作** (`exercises/04_文件操作练习.md`)
   - 文件读写
   - CSV和JSON处理
   - 文件路径操作
   - 日志处理

5. **数据处理** (`exercises/05_数据处理练习.md`)
   - NumPy数组操作
   - Pandas数据处理
   - 数据清洗
   - 数据可视化

## ❓ 常见问题

### Q: 如何运行Python脚本？

A: 在命令行中：
```bash
python script.py
```

### Q: 如何安装第三方库？

A: 使用pip：
```bash
pip install 库名
```

### Q: 遇到编码错误怎么办？

A: 在文件开头添加：
```python
# -*- coding: utf-8 -*-
```

### Q: 如何调试代码？

A: 
1. 使用 `print()` 输出中间值
2. 使用 `pdb` 调试器
3. 使用IDE的调试功能
