## 练习2：CSV文件处理

### 任务
1. 从 `data/employees.csv` 读取员工数据
2. 实现以下功能：
   - 显示所有员工
   - 添加新员工
   - 根据ID查找员工
   - 更新员工信息
   - 删除员工
   - 按工资排序
3. 将修改后的数据保存回CSV文件

### 数据格式
```csv

001,张三,技术部,8000
002,李四,销售部,6000
```

### 要求
- 使用 `csv` 模块
- 使用 `csv.DictReader` 和 `csv.DictWriter`
- 实现完整的CRUD操作
