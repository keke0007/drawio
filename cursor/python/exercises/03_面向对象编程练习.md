# Python 面向对象编程练习

## 练习1：类和对象基础

### 任务
创建一个 `Student` 类：
1. 属性：姓名、年龄、学号、成绩
2. 方法：
   - `__init__()` - 初始化
   - `__str__()` - 字符串表示
   - `get_grade()` - 获取等级
   - `update_score()` - 更新成绩

### 要求
- 使用 `data/students.csv` 创建学生对象
- 打印学生信息

## 练习4：继承

   - 方法：`eat()`, `sleep()`, `make_sound()`
2. 派生类：
   - `Dog` - 重写 `make_sound()`
   - `Cat` - 重写 `make_sound()`

### 要求
- 实现继承
- 方法重写

## 练习10：综合案例：学生成绩管理系统

### 任务
创建学生成绩管理系统：
1. `Course` 类：

2. `Student` 类：

### 要求
- 多个类协作
- 复杂的数据处理
- 文件IO操作
