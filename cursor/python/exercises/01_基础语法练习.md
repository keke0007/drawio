## 练习1：变量和数据类型

### 任务
创建一个Python脚本，完成以下操作：
1. 定义不同类型的变量（整数、浮点数、字符串、布尔值）
2. 打印变量的值和类型
3. 进行类型转换

### 数据文件
使用 `data/basic_data.txt` 中的数据

### 示例代码结构
```python
# 定义变量
name = "张三"
age = 25
height = 175.5
is_student = True

# 打印类型
print(type(name))
print(type(age))

# 类型转换
age_str = str(age)
height_int = int(height)
```

### 要求
- 使用 `data/basic_data.txt` 中的数据
- 完成所有类型转换
- 输出格式化的结果
