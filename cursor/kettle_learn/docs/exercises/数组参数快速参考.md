# Kettle 数组参数快速参考

## 📋 核心概念

Kettle不直接支持数组类型参数，但可以通过以下方式实现数组功能：

### 1. 数组参数格式
- **传递方式**：使用逗号分隔的字符串
- **示例**：`"1,2,3,4,5"`
- **类型**：String

### 2. 数组拆分方法

#### 方法A：拆分字段（最简单）
```
生成记录（id_array = ${ID_ARRAY}）
    ↓
拆分字段（分隔符：,）
    ↓
结果：每行一个ID
```

#### 方法B：JavaScript split()
```javascript
var ids = ID_ARRAY.split(",");
// 处理数组
```

#### 方法C：正则表达式
```javascript
var ids = ID_ARRAY.match(/\d+/g);
```

## 🔄 循环删除的标准流程

### 完整流程图
```
定义参数（ID_ARRAY = "1,2,3"）
    ↓
生成记录（创建一行数据）
    ↓
拆分字段（拆分成多行）
    ↓
执行SQL脚本（执行每行 = 是）
    ↓
删除完成
```

### 关键配置

#### 1. 参数定义
```
参数名：ID_ARRAY
默认值：1,2,3
类型：String
```

#### 2. 生成记录步骤
- 限制：1
- 字段：`id_array` = `${ID_ARRAY}`

#### 3. 拆分字段步骤
- 拆分字段：`id_array`
- 分隔符：`,`
- 新字段名：`record_id`

#### 4. 执行SQL脚本步骤
- SQL语句：`DELETE FROM table_name WHERE id = ?`
- 参数：`record_id`
- **执行每行**：✅ **必须勾选！**

## 💻 代码示例

### 示例1：基本循环删除
```kettle
# 步骤1：生成记录
id_array = ${ID_ARRAY}  # "1,2,3,4,5"

# 步骤2：拆分字段
输入：id_array = "1,2,3,4,5"
输出：
  record_id = "1"
  record_id = "2"
  record_id = "3"
  record_id = "4"
  record_id = "5"

# 步骤3：执行SQL脚本
DELETE FROM employees WHERE id = ?
参数：record_id
执行每行：是
```

### 示例2：使用IN子句（批量删除）
```sql
-- 直接使用参数（需要确保格式正确）
DELETE FROM employees WHERE id IN (${ID_ARRAY})

-- 或使用JavaScript构建
var ids = ID_ARRAY.split(",").map(id => id.trim()).join(",");
var sql = "DELETE FROM employees WHERE id IN (" + ids + ")";
```

### 示例3：参数验证
```javascript
// 验证数组参数
if (ID_ARRAY == null || ID_ARRAY == "") {
    throw new Error("ID_ARRAY参数不能为空");
}

// 清理和验证ID
var cleanIds = ID_ARRAY.split(",")
    .map(function(id) { return id.trim(); })
    .filter(function(id) { 
        return id != "" && !isNaN(id); 
    });

var validIdArray = cleanIds.join(",");
```

## 🎯 常见应用场景

### 场景1：批量删除
```sql
DELETE FROM table_name WHERE id = ?
```
- 使用拆分字段 + 执行SQL脚本
- 执行每行：是

### 场景2：批量更新
```sql
UPDATE table_name SET status = 'deleted' WHERE id = ?
```
- 同删除流程，只需修改SQL

### 场景3：批量查询
```sql
SELECT * FROM table_name WHERE id = ?
```
- 使用表输入步骤
- 执行每行：是

### 场景4：批量插入
```kettle
拆分字段 → 添加常量字段 → 表输出
```

## ⚠️ 注意事项

### 1. 执行每行设置
- **必须勾选**"执行每行"选项
- 否则只会执行一次，不会循环

### 2. 参数化查询
- 使用 `?` 占位符，不要直接拼接
- 防止SQL注入攻击

### 3. 性能考虑
- 少量数据：使用循环删除
- 大量数据：使用IN子句批量删除
- 超大量数据：分批处理

### 4. 事务管理
- 大量删除时考虑事务
- 可以设置批处理大小

### 5. 错误处理
- 添加错误处理步骤
- 记录删除失败的ID
- 使用"中止"步骤处理严重错误

## 🔍 调试技巧

### 1. 查看拆分结果
- 在拆分字段后添加"表输出"或"CSV输出"
- 查看拆分后的数据是否正确

### 2. 测试单个ID
- 先测试单个ID：`ID_ARRAY = "1"`
- 确认流程正确后再测试多个

### 3. 使用预览数据
- 右键步骤 → 预览数据
- 查看每步的输出结果

### 4. 添加日志
- 在执行SQL前添加"表输出"
- 记录要删除的ID列表

## 📊 性能对比

| 方法 | 适用场景 | 性能 | 复杂度 |
|------|---------|------|--------|
| 拆分字段 + 循环删除 | 少量数据（<100） | 较慢 | 简单 |
| IN子句批量删除 | 中等数据（100-1000） | 快 | 简单 |
| 分批处理 | 大量数据（>1000） | 最快 | 复杂 |
