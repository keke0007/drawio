# 练习4：数据过滤和排序

## 目标
学习如何根据条件过滤数据并对结果进行排序。

## 数据文件
- 输入：`data/input/employees.csv`
- 输出：`data/output/employees_filtered.csv`

## 步骤
1. CSV文件输入（读取employees.csv）
2. 添加"过滤记录"步骤
   - 条件：`salary > 7000 AND department = '技术部'`
   - 发送true数据到：下一步
   - 发送false数据到：空操作（可选）
3. 添加"排序记录"步骤
   - 排序字段：salary（降序）
   - 次要排序：name（升序）
4. CSV文件输出
5. 连接并运行

## 知识点
- 条件过滤
- 多条件组合（AND/OR）
- 数据排序
- 多字段排序

# 练习5：数据分组和聚合

## 目标
学习如何对数据进行分组和聚合计算。

## 数据文件
- 输入：`data/input/employees.csv`
- 输出：`data/output/department_summary.csv`

## 步骤
1. CSV文件输入（读取employees.csv）
2. 添加"分组"步骤
   - 分组字段：department
   - 聚合字段：
     - 员工数量：COUNT(name)
     - 平均工资：AVG(salary)
     - 最高工资：MAX(salary)
     - 最低工资：MIN(salary)
     - 工资总和：SUM(salary)
3. CSV文件输出
4. 连接并运行

## 知识点
- 数据分组
- 聚合函数（COUNT, SUM, AVG, MAX, MIN）
- 分组统计

# 练习6：字段计算和字符串处理

## 目标
学习如何使用计算器和字符串操作处理字段。

## 数据文件
- 输入：`data/input/employees.csv`
- 输出：`data/output/employees_calculated.csv`

## 步骤
1. CSV文件输入（读取employees.csv）
2. 添加"计算器"步骤
   - 新增字段：annual_salary
   - 计算：salary * 12
   - 新增字段：bonus
   - 计算：salary * 0.1（10%奖金）
   - 新增字段：total_income
   - 计算：annual_salary + bonus
3. 添加"字符串操作"步骤
   - 操作：大写转换（name -> name_upper）
   - 操作：小写转换（email -> email_lower）
   - 操作：字符串长度（name -> name_length）
4. CSV文件输出
5. 连接并运行

## 知识点
- 数值计算
- 字符串转换
- 字符串函数
- 字段计算

# 练习7：值映射和替换

## 目标
学习如何进行值映射和NULL值处理。

## 数据文件
- 输入：`data/input/employees.csv`
- 输出：`data/output/employees_mapped.csv`

## 步骤
1. CSV文件输入（读取employees.csv）
2. 添加"值映射"步骤
   - 字段：department
   - 映射规则：
     - 技术部 -> IT
     - 销售部 -> Sales
     - 人事部 -> HR
     - 财务部 -> Finance
3. 添加"替换NULL值"步骤
   - 字段：salary
   - 替换值：0（如果salary为NULL）
4. 添加"增加常量"步骤
   - 字段名：status
   - 值：Active
5. CSV文件输出
6. 连接并运行

## 知识点
- 值映射
- NULL值处理
- 常量添加
