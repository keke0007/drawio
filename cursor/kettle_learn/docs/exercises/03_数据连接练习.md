# 练习8：表连接和查询

## 目标
学习如何连接多个数据源并进行关联查询。

## 数据文件
- 输入1：`data/input/employees.csv`
- 输入2：`data/input/sales.csv`
- 输出：`data/output/employee_sales.csv`

## 步骤
1. CSV文件输入1（读取employees.csv）
2. CSV文件输入2（读取sales.csv）
3. 添加"流查询"步骤
   - 主数据流：employees
   - 查询数据流：sales
   - 连接字段：employees.id = sales.employee_id
   - 返回字段：quantity, amount, sale_date
4. CSV文件输出
5. 连接并运行

## 知识点
- 多数据源输入
- 流查询（Stream Lookup）
- 字段关联
- 数据连接

# 练习9：数据合并

## 目标
学习如何合并多个数据源。

## 数据文件
- 输入1：`data/input/employees.csv`
- 输入2：`data/input/products.csv`
- 输出：`data/output/merged_data.csv`

## 步骤
1. CSV文件输入1（读取employees.csv）
2. CSV文件输入2（读取products.csv）
3. 添加"合并记录"步骤
   - 主数据流：employees
   - 参考数据流：products
   - 关键字段：无（简单合并）
   - 标志字段：source（标识数据来源）
4. CSV文件输出
5. 连接并运行

## 知识点
- 数据合并
- 合并记录
- 数据源标识

# 练习10：数据去重

## 目标
学习如何去除重复数据。

## 数据文件
- 输入：`data/input/sales.csv`（可以复制几行创建重复数据）
- 输出：`data/output/sales_unique.csv`

## 步骤
1. CSV文件输入（读取sales.csv）
2. 添加"唯一行"步骤
   - 比较字段：sale_id, product_id, employee_id
3. 或者使用"记录去重"步骤
   - 去重字段：sale_id
4. CSV文件输出
5. 连接并运行

## 知识点
- 数据去重
- 唯一行
- 记录去重
- 去重策略
