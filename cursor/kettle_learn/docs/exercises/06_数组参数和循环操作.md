# 练习22：数组参数和循环删除

## 目标
学习如何在Kettle中使用数组参数，并通过循环执行删除操作。

## 场景描述
需要根据传入的ID数组，循环删除数据库中的多条记录。

## 数据准备
假设有一个员工表，需要根据传入的员工ID数组批量删除记录。

## 方法一：使用生成记录 + 执行SQL脚本

### 步骤1：定义数组参数
1. 创建新转换
2. 编辑 -> 设置转换参数
3. 添加参数：
   - `ID_ARRAY` (默认值：1,2,3,4,5，类型：String)
   - 说明：以逗号分隔的ID字符串

### 步骤2：将数组参数拆分成多行
1. 添加"生成记录"步骤
   - 限制：1（只生成一行）
   - 字段：`id_array` = `${ID_ARRAY}`

2. 添加"拆分字段"步骤
   - 拆分字段：`id_array`
   - 分隔符：`,`（逗号）
   - 新字段名：`id_value`
   - 结果：将 "1,2,3,4,5" 拆分成5行，每行一个ID

### 步骤3：执行循环删除
1. 添加"执行SQL脚本"步骤
   - 数据库连接：选择你的数据库连接
   - SQL语句：
   ```sql
   DELETE FROM employees WHERE id = ?
   ```
   - 参数：选择 `id_value` 字段
   - 执行每行：是（重要！）

2. 连接步骤并运行

### 完整流程
```
生成记录 → 拆分字段 → 执行SQL脚本
```

2. 添加"JavaScript代码"步骤
   ```javascript

   var inClause = ids.map(function(id) {
       return id.trim(); // 去除空格
   }).join(",");
   
   // 构建完整的SQL
   var sql = "DELETE FROM employees WHERE id IN (" + inClause + ")";
   ```

## 最佳实践：完整的数组参数删除流程

### 步骤1：参数定义和验证
1. 定义参数：
   - `ID_ARRAY` (默认值：1,2,3)
   - `TABLE_NAME` (默认值：employees)
   - `ID_COLUMN` (默认值：id)

2. 添加"JavaScript代码"步骤验证参数
   ```javascript
   // 验证ID数组不为空
   if (ID_ARRAY == null || ID_ARRAY == "") {
       throw new Error("ID_ARRAY参数不能为空");
   }
   
   // 验证表名
   if (TABLE_NAME == null || TABLE_NAME == "") {
       throw new Error("TABLE_NAME参数不能为空");
   }
   
   // 清理ID数组（去除空格）
   var cleanIds = ID_ARRAY.split(",").map(function(id) {
       return id.trim();
   }).filter(function(id) {
       return id != "" && !isNaN(id); // 验证是否为数字
   });
   
   var validIdArray = cleanIds.join(",");
   ```

### 步骤2：拆分数组
1. 添加"生成记录"步骤
   - 字段：`id_array` = `${validIdArray}`

2. 添加"拆分字段"步骤
   - 拆分字段：`id_array`
   - 分隔符：`,`
   - 新字段名：`record_id`

### 步骤3：执行删除
1. 添加"执行SQL脚本"步骤
   - 数据库连接：选择连接
   - SQL语句：
   ```sql
   DELETE FROM ${TABLE_NAME} WHERE ${ID_COLUMN} = ?
   ```
   - 参数：`record_id`
   - 执行每行：是

2. 添加"表输出"步骤（记录删除日志，可选）
   - 输出删除的记录ID和删除时间

### 完整流程图
```
生成记录（参数验证）
    ↓
拆分字段（数组拆分）
    ↓
执行SQL脚本（循环删除）
    ↓
表输出（日志记录）
```

## 知识点总结

### 1. 数组参数传递
- Kettle不直接支持数组类型参数
- 使用逗号分隔的字符串：`"1,2,3,4,5"`
- 在转换中通过拆分处理

### 2. 数组拆分方法
- **拆分字段**：最简单直接
- **JavaScript split()**：更灵活，可处理复杂格式
- **正则表达式**：处理复杂分隔符

### 3. 循环执行SQL
- **执行每行**：在"执行SQL脚本"中勾选"执行每行"
- **参数化查询**：使用 `?` 占位符，避免SQL注入
- **批量执行**：对于大量数据，考虑批量删除

### 4. 安全考虑
- 参数验证：检查数组格式和内容
- SQL注入防护：使用参数化查询
- 事务控制：大量删除时考虑事务管理
- 日志记录：记录删除操作便于审计

# 练习23：数组参数的其他应用场景

## 场景1：批量查询

### 需求
根据ID数组批量查询记录

### 实现
```sql
SELECT * FROM employees WHERE id IN (${ID_ARRAY})
```

或使用参数化查询：
1. 拆分数组
2. 使用"表输入"步骤
3. SQL：`SELECT * FROM employees WHERE id = ?`
4. 执行每行：是

## 场景2：批量插入

### 需求
根据数组参数批量插入记录

### 实现
1. 拆分数组
2. 添加常量字段（其他必填字段）
3. 使用"表输出"步骤批量插入

## 场景3：条件过滤

### 需求
根据多个条件数组进行过滤

### 实现
1. 定义多个数组参数：`DEPT_ARRAY`, `STATUS_ARRAY`
2. 分别拆分
3. 使用"流查询"或"数据库查询"进行匹配

## 场景4：动态表名和字段名

### 需求
根据数组参数动态选择表和字段

### 实现
使用JavaScript构建动态SQL：
```javascript
var tableArray = TABLE_ARRAY.split(",");
var sql = "SELECT * FROM " + tableArray[0] + " WHERE id IN (" + ID_ARRAY + ")";
```
