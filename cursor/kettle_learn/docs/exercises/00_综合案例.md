# 综合案例：员工薪资分析系统

## 案例描述
创建一个完整的ETL流程，分析员工薪资数据，生成部门统计报告和薪资等级分布。

## 数据文件
- `data/input/employees.csv` - 员工基本信息
- `data/input/salary_grades.txt` - 薪资等级表

## 需求
1. 读取员工数据
2. 根据薪资匹配薪资等级
3. 计算年度薪资和奖金
4. 按部门统计：
   - 员工数量
   - 平均薪资
   - 最高/最低薪资
   - 薪资总和
5. 按薪资等级统计员工分布
6. 输出多个报表文件

## 实现步骤

### 步骤1：数据输入
- 使用"CSV文件输入"读取employees.csv
- 使用"文本文件输入"读取salary_grades.txt（分隔符：|）

### 步骤2：数据转换
- 使用"计算器"计算年度薪资（salary * 12）
- 使用"流查询"匹配薪资等级
- 使用"计算器"计算奖金（salary * bonus_rate）

### 步骤3：数据分组
- 使用"分组"按部门统计
- 使用"分组"按薪资等级统计

### 步骤4：数据输出
- 输出部门统计到：`data/output/department_stats.csv`
- 输出薪资等级分布到：`data/output/salary_grade_distribution.csv`
- 输出详细员工信息到：`data/output/employees_detail.csv`

## 扩展练习
1. 添加数据验证（薪资范围检查）
2. 添加错误处理
3. 创建作业，定时执行
4. 添加邮件通知功能

# 综合案例：销售数据分析系统

## 案例描述
整合销售数据、员工数据和产品数据，生成销售分析报告。

## 数据文件
- `data/input/sales.csv` - 销售记录
- `data/input/employees.csv` - 员工信息
- `data/input/products.csv` - 产品信息

## 需求
1. 关联销售记录、员工信息和产品信息
2. 计算销售总额、平均销售额
3. 按员工统计销售业绩
4. 按产品统计销售情况
5. 按日期统计销售趋势
6. 生成多维度分析报告

## 实现步骤

### 步骤1：多数据源输入
- 读取sales.csv
- 读取employees.csv
- 读取products.csv

### 步骤2：数据关联
- 使用"流查询"关联sales和employees（通过employee_id）
- 使用"流查询"关联sales和products（通过product_id）

### 步骤3：数据计算
- 计算销售总额
- 计算销售利润（假设利润率为20%）
- 计算销售数量

### 步骤4：数据分组统计
- 按员工分组统计
- 按产品分组统计
- 按日期分组统计

### 步骤5：数据输出
- 员工销售业绩：`data/output/employee_sales_performance.csv`
- 产品销售分析：`data/output/product_sales_analysis.csv`
- 销售趋势分析：`data/output/sales_trend.csv`

## 扩展练习
1. 添加TOP N分析（销售前10名员工）
2. 添加同比/环比分析
3. 生成可视化数据（JSON格式）
4. 创建定时作业，每天自动生成报告
