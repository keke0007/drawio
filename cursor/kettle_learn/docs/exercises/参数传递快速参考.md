# Kettle 参数传递快速参考

## 📋 参数类型概览

### 1. 转换参数（Transformation Parameters）
- **定义位置**：编辑 -> 设置转换参数
- **引用方式**：`${参数名}`
- **作用域**：仅在当前转换内有效
- **用途**：动态配置转换行为

### 2. 作业参数（Job Parameters）
- **定义位置**：编辑 -> 设置作业参数
- **引用方式**：`${参数名}`
- **作用域**：当前作业及子作业/转换
- **用途**：作业级别的配置

### 3. 系统变量（System Variables）
- **定义位置**：Kettle内置
- **引用方式**：`${变量名}`
- **作用域**：全局
- **用途**：获取系统信息

### 4. 命名参数（Named Parameters）
- **定义位置**：编辑 -> 设置命名参数
- **引用方式**：通过参数集选择
- **作用域**：当前转换/作业
- **用途**：多场景配置切换

## 🔧 常用系统变量

### 文件路径变量
```
${Internal.Transformation.Filename.Directory}  - 转换文件目录
${Internal.Transformation.Filename.Name}        - 转换文件名
${Internal.Job.Filename.Directory}               - 作业文件目录
${Internal.Job.Filename.Name}                   - 作业文件名
${Internal.Entry.Current.Directory}             - 当前工作目录
```

### 日期时间变量
```
${Internal.Transformation.Date.YYYYMMDD}        - 日期：20240125
${Internal.Transformation.Date.YYYY-MM-DD}      - 日期：2024-01-25
${Internal.Transformation.Date.HHmmss}          - 时间：143025
${Internal.Transformation.Date.YYYYMMDDHHmmss}  - 日期时间：20240125143025
```

### 系统信息变量
```
${Internal.Transformation.Filename.Directory}   - 转换目录
${Internal.Transformation.Filename.Name}       - 转换文件名
${Internal.Transformation.Filename.BaseName}    - 转换文件名（不含扩展名）
```

## 📝 参数定义语法

### 转换参数定义
```
参数名 | 默认值 | 描述
MIN_SALARY | 7000 | 最低薪资
OUTPUT_FILE | output.csv | 输出文件名
```

### 作业参数定义
```
参数名 | 默认值 | 描述
INPUT_PATH | data/input | 输入路径
OUTPUT_PATH | data/output | 输出路径
```

## 🔗 参数传递链

### 作业 -> 转换
```
作业参数 (JOB_PARAM)
    ↓ (在转换步骤中设置参数映射)
转换参数 (TRANS_PARAM = ${JOB_PARAM})
```

### 作业 -> 子作业 -> 转换
```
主作业参数 (MAIN_PARAM)
    ↓
子作业参数 (SUB_PARAM = ${MAIN_PARAM})
    ↓
转换参数 (TRANS_PARAM = ${SUB_PARAM})
```

## 💻 命令行参数

### Kitchen（执行作业）
```cmd
kitchen.bat /file:"job.kjb" /param:PARAM1="value1" /param:PARAM2=value2
```

### Pan（执行转换）
```cmd
pan.bat /file:"trans.ktr" /param:PARAM1="value1" /param:PARAM2=value2
```

### 参数格式
- 字符串参数：`/param:NAME="value"`
- 数值参数：`/param:NAME=123`
- 布尔参数：`/param:NAME=true`

## 🎯 最佳实践

### 1. 参数命名规范
- 使用大写字母和下划线：`MIN_SALARY`
- 使用有意义的名称：`OUTPUT_FILE_PATH`
- 避免使用系统变量名

### 2. 默认值设置
- 总是设置合理的默认值
- 默认值应该适用于开发环境
- 生产环境通过参数覆盖

### 3. 参数验证
- 使用JavaScript验证参数
- 检查参数类型和范围
- 无效参数使用默认值或报错

### 4. 参数文档
- 为每个参数添加描述
- 说明参数的用途和取值范围
- 记录参数的使用场景

### 5. 环境配置
- 使用参数集区分环境（dev/test/prod）
- 不同环境使用不同的默认值
- 通过配置文件管理参数

## ⚠️ 常见错误

### 错误1：参数未定义
```
错误：参数 ${PARAM_NAME} 未定义
解决：在转换/作业属性中定义参数
```

### 错误2：参数类型不匹配
```
错误：参数类型错误
解决：检查参数类型（String/Integer/Number/Boolean）
```

### 错误3：参数引用错误
```
错误：无法解析变量 ${PARAM_NAME}
解决：检查参数名拼写，使用 ${参数名} 格式
```

### 错误4：参数传递失败
```
错误：子转换未收到参数
解决：在作业的转换步骤中设置参数映射
```

## 📚 示例代码

### 示例1：基本参数使用
```kettle
# 转换参数定义
MIN_SALARY = 7000
OUTPUT_FILE = employees_output.csv

# 在过滤记录中使用
salary > ${MIN_SALARY}

# 在文件输出中使用
data/output/${OUTPUT_FILE}
```

### 示例2：动态文件路径
```kettle
# 使用系统变量构建路径
${Internal.Transformation.Filename.Directory}/../data/output/employees_${Internal.Transformation.Date.YYYYMMDD}.csv
```

### 示例3：参数验证
```javascript
// JavaScript代码步骤
var minSalary = parseInt(MIN_SALARY);
if (isNaN(minSalary) || minSalary < 0) {
    minSalary = 5000; // 使用默认值
}
```
