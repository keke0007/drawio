## 🎯 学习建议

1. **循序渐进**：按照练习顺序依次完成，不要跳跃
2. **动手实践**：每个练习都要在Kettle中实际操作
3. **理解原理**：不仅要会操作，还要理解每个步骤的作用
4. **举一反三**：完成练习后，尝试修改参数和条件
5. **记录问题**：遇到问题及时记录，便于复习

## 💡 常见问题

### Q1: 如何打开Kettle？
A: 运行Spoon.bat（Windows）或Spoon.sh（Linux/Mac）

### Q2: 如何创建新转换？
A: 文件 -> 新建 -> 转换

### Q3: 如何运行转换？
A: 点击运行按钮（绿色三角形）或按F9

### Q4: 如何查看步骤输出？
A: 运行后点击步骤，查看"预览数据"

### Q5: 如何调试转换？
A: 使用"预览数据"功能，逐步检查每个步骤的输出
