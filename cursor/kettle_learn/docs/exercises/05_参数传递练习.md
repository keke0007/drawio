# 练习15：转换参数（Transformation Parameters）

## 目标
学习如何在转换中使用参数，实现动态配置。

## 数据文件
- 输入：`data/input/employees.csv`
- 输出：`data/output/employees_param_output.csv`

## 需求
使用参数动态控制：
- 薪资过滤条件（最低薪资）
- 输出文件名
- 部门过滤条件

## 步骤

### 步骤1：创建转换并定义参数
1. 创建新转换
2. 在转换属性中定义参数：
   - 编辑 -> 设置转换参数
   - 添加参数：
     - `MIN_SALARY` (默认值：7000，类型：Integer)
     - `OUTPUT_FILE` (默认值：employees_output.csv，类型：String)
     - `DEPT_FILTER` (默认值：技术部，类型：String)

### 步骤2：使用参数
1. CSV文件输入（读取employees.csv）
2. 添加"过滤记录"步骤
   - 条件：`salary > ${MIN_SALARY} AND department = '${DEPT_FILTER}'`
   - 注意：使用 `${参数名}` 引用参数
3. 添加"CSV文件输出"步骤
   - 文件名：`data/output/${OUTPUT_FILE}`
   - 使用参数引用文件名

### 步骤3：运行转换
1. 直接运行：使用默认参数值
2. 带参数运行：
   - 运行 -> 设置运行参数
   - 设置参数值：
     - MIN_SALARY = 8000
     - OUTPUT_FILE = high_salary_employees.csv
     - DEPT_FILTER = 销售部

## 知识点
- 转换参数定义
- 参数引用语法 `${参数名}`
- 参数类型（String, Integer, Number, Boolean）
- 运行参数设置

# 练习16：作业参数（Job Parameters）

## 目标
学习如何在作业中使用参数，并传递给子转换。

## 数据文件
- 输入：`data/input/employees.csv`
- 输出：`data/output/employees_job_output.csv`

## 需求
创建作业，通过参数控制：
- 数据源文件路径
- 输出文件路径
- 处理日期

## 步骤

### 步骤1：创建转换（使用参数）
1. 创建转换：`transformations/01_basic/employee_process.ktr`
2. 定义转换参数：
   - `INPUT_FILE` (默认值：data/input/employees.csv)
   - `OUTPUT_FILE` (默认值：data/output/employees_output.csv)
   - `PROCESS_DATE` (默认值：${Internal.Job.Filename.Directory}/../data/input/employees.csv)
3. 在转换中使用参数：
   - CSV文件输入：文件名 = `${INPUT_FILE}`
   - 添加常量：process_date = `${PROCESS_DATE}`
   - CSV文件输出：文件名 = `${OUTPUT_FILE}`

### 步骤2：创建作业（传递参数）
1. 创建新作业
2. 定义作业参数：
   - 编辑 -> 设置作业参数
   - 添加参数：
     - `INPUT_PATH` (默认值：data/input/employees.csv)
     - `OUTPUT_PATH` (默认值：data/output/employees_job_output.csv)
     - `PROCESS_DATE` (默认值：2024-01-25)
3. 添加"START"步骤
4. 添加"转换"步骤
   - 选择转换文件：`transformations/01_basic/employee_process.ktr`
   - 在"参数"标签页设置参数映射：
     - INPUT_FILE = ${INPUT_PATH}
     - OUTPUT_FILE = ${OUTPUT_PATH}
     - PROCESS_DATE = ${PROCESS_DATE}
5. 添加"成功"步骤
6. 连接步骤并运行

## 知识点
- 作业参数定义
- 参数传递给子转换
- 参数映射
- 作业和转换参数的区别

# 练习17：变量和系统变量

## 目标
学习如何使用Kettle内置变量和自定义变量。

## 数据文件
- 输入：`data/input/employees.csv`
- 输出：`data/output/employees_var_output.csv`

## 需求
使用变量实现：
- 动态文件路径（基于日期）
- 使用系统变量获取当前时间
- 自定义变量计算

## 步骤

### 步骤1：使用系统变量
1. 创建新转换
2. CSV文件输入（读取employees.csv）
3. 添加"获取系统信息"步骤
   - 获取系统变量：
     - `system_date` = 系统日期
     - `system_time` = 系统时间
     - `user_name` = 用户名
     - `hostname` = 主机名
4. 添加"计算器"步骤
   - 使用变量：`${Internal.Transformation.Filename.Directory}`
   - 构建动态路径：`${Internal.Transformation.Filename.Directory}/../data/output/employees_${system_date}.csv`

### 步骤2：使用变量构建文件名
1. 在CSV文件输出中使用变量：
   - 文件名：`data/output/employees_${Internal.Transformation.Date.YYYYMMDD}.csv`
   - 或者：`data/output/employees_${system_date}.csv`

### 步骤3：常用系统变量
- `${Internal.Transformation.Filename.Directory}` - 转换文件所在目录
- `${Internal.Transformation.Filename.Name}` - 转换文件名
- `${Internal.Transformation.Date.YYYYMMDD}` - 当前日期（YYYYMMDD格式）
- `${Internal.Transformation.Date.YYYY-MM-DD}` - 当前日期（YYYY-MM-DD格式）
- `${Internal.Job.Filename.Directory}` - 作业文件所在目录
- `${Internal.Entry.Current.Directory}` - 当前工作目录

## 知识点
- 系统变量使用
- 变量引用语法
- 日期时间变量
- 文件路径变量

# 练习18：命名参数和参数集

## 目标
学习如何使用命名参数和参数集，实现多场景配置。

## 数据文件
- 输入：`data/input/employees.csv`
- 输出：多个输出文件（根据参数集）

## 需求
创建参数集，实现不同场景的配置：
- 场景1：技术部员工分析
- 场景2：销售部员工分析
- 场景3：高薪资员工分析

## 步骤

### 步骤1：定义参数集
1. 创建新转换
2. 编辑 -> 设置转换参数
3. 添加参数：
   - `DEPT_NAME` (默认值：技术部)
   - `MIN_SALARY` (默认值：7000)
   - `OUTPUT_SUFFIX` (默认值：tech)
4. 编辑 -> 设置命名参数
5. 创建参数集：
   - **参数集1：技术部分析**
     - DEPT_NAME = 技术部
     - MIN_SALARY = 7000
     - OUTPUT_SUFFIX = tech
   - **参数集2：销售部分析**
     - DEPT_NAME = 销售部
     - MIN_SALARY = 6000
     - OUTPUT_SUFFIX = sales
   - **参数集3：高薪资分析**
     - DEPT_NAME = （空，不过滤部门）
     - MIN_SALARY = 8000
     - OUTPUT_SUFFIX = high_salary

### 步骤2：使用参数集
1. CSV文件输入（读取employees.csv）
2. 添加"过滤记录"步骤
   - 条件：根据参数动态构建
   - 如果DEPT_NAME不为空：`department = '${DEPT_NAME}' AND salary >= ${MIN_SALARY}`
   - 如果DEPT_NAME为空：`salary >= ${MIN_SALARY}`
3. 添加"CSV文件输出"步骤
   - 文件名：`data/output/employees_${OUTPUT_SUFFIX}.csv`

### 步骤3：运行不同参数集
1. 运行 -> 设置运行参数
2. 选择不同的参数集
3. 或手动设置参数值

## 知识点
- 命名参数定义
- 参数集管理
- 参数集切换
- 条件参数使用

# 练习19：命令行参数

## 目标
学习如何通过命令行传递参数执行转换和作业。

## 数据文件
- 输入：`data/input/employees.csv`
- 输出：`data/output/employees_cmd_output.csv`

## 需求
通过命令行执行转换，传递参数：
- 输入文件路径
- 输出文件路径
- 最低薪资

## 步骤

### 步骤1：准备转换
1. 创建转换：`transformations/01_basic/employee_cmd.ktr`
2. 定义参数：
   - `INPUT_FILE` (默认值：data/input/employees.csv)
   - `OUTPUT_FILE` (默认值：data/output/employees_output.csv)
   - `MIN_SALARY` (默认值：7000)
3. 在转换中使用这些参数

### 步骤2：命令行执行
1. 打开命令行（CMD或PowerShell）
2. 切换到Kettle安装目录的data-integration文件夹
3. 执行命令：

**Windows:**
```cmd
kitchen.bat /file:"C:\Users\ke\Desktop\kettle_learn\jobs\employee_job.kjb" /param:INPUT_FILE="data/input/employees.csv" /param:OUTPUT_FILE="data/output/employees_cmd_output.csv" /param:MIN_SALARY=8000
```

**Linux/Mac:**
```bash
./kitchen.sh /file:"/path/to/job.kjb" /param:INPUT_FILE="data/input/employees.csv" /param:OUTPUT_FILE="data/output/employees_cmd_output.csv" /param:MIN_SALARY=8000
```

**执行转换（使用Pan）:**
```cmd
pan.bat /file:"C:\Users\ke\Desktop\kettle_learn\transformations\01_basic\employee_cmd.ktr" /param:INPUT_FILE="data/input/employees.csv" /param:OUTPUT_FILE="data/output/employees_cmd_output.csv" /param:MIN_SALARY=8000
```

### 步骤3：批处理脚本
创建批处理文件 `run_employee_analysis.bat`:
```batch
@echo off
set KETTLE_HOME=C:\kettle\data-integration
set INPUT_FILE=data/input/employees.csv
set OUTPUT_FILE=data/output/employees_cmd_output.csv
set MIN_SALARY=8000

cd %KETTLE_HOME%
call kitchen.bat /file:"C:\Users\ke\Desktop\kettle_learn\jobs\employee_job.kjb" /param:INPUT_FILE="%INPUT_FILE%" /param:OUTPUT_FILE="%OUTPUT_FILE%" /param:MIN_SALARY=%MIN_SALARY%
```

## 知识点
- Kitchen命令（执行作业）
- Pan命令（执行转换）
- 命令行参数传递
- 批处理脚本
- 参数格式：`/param:参数名=参数值`

# 练习20：参数验证和默认值

## 目标
学习如何验证参数有效性，设置合理的默认值。

## 数据文件
- 输入：`data/input/employees.csv`
- 输出：`data/output/employees_validated.csv`

## 需求
实现参数验证：
- 检查参数是否为空
- 检查参数类型是否正确
- 设置合理的默认值
- 参数无效时使用默认值或报错

## 步骤

### 步骤1：参数验证逻辑
1. 创建新转换
2. 定义参数：
   - `MIN_SALARY` (默认值：5000，类型：Integer)
   - `MAX_SALARY` (默认值：10000，类型：Integer)
   - `DEPT_NAME` (默认值：，类型：String)
3. 使用JavaScript验证参数：
   ```javascript
   // 验证薪资范围
   var minSalary = parseInt(MIN_SALARY);
   var maxSalary = parseInt(MAX_SALARY);
   
   if (isNaN(minSalary) || minSalary < 0) {
       minSalary = 5000; // 使用默认值
   }
   
   if (isNaN(maxSalary) || maxSalary < minSalary) {
       maxSalary = 10000; // 使用默认值
   }
   
   // 验证部门名称
   var deptName = DEPT_NAME;
   if (deptName == null || deptName == "") {
       deptName = ""; // 不过滤部门
   }
   ```

### 步骤2：使用验证后的参数
1. CSV文件输入（读取employees.csv）
2. 添加"JavaScript代码"步骤
   - 验证并修正参数值
   - 输出验证后的参数
3. 添加"过滤记录"步骤
   - 使用验证后的参数值

### 步骤3：错误处理
1. 添加"数据验证"步骤
   - 验证参数范围
   - 如果参数无效，记录错误
2. 添加"中止"步骤
   - 参数严重错误时中止转换

## 知识点
- 参数验证
- 默认值设置
- 参数类型检查
- 错误处理
- JavaScript参数验证

# 练习21：参数传递到子转换和子作业

## 目标
学习如何在多层级的转换和作业中传递参数。

## 数据文件
- 输入：`data/input/employees.csv`
- 输出：`data/output/employees_nested_output.csv`

## 需求
创建主作业 -> 子作业 -> 转换的层级结构，传递参数。

## 步骤

### 步骤1：创建子转换
1. 创建转换：`transformations/01_basic/sub_transformation.ktr`
2. 定义参数：`PROCESS_TYPE`, `OUTPUT_PATH`
3. 根据PROCESS_TYPE执行不同逻辑

### 步骤2：创建子作业
1. 创建作业：`jobs/sub_job.kjb`
2. 定义参数：`MAIN_PARAM`
3. 添加转换步骤，调用子转换
4. 将MAIN_PARAM传递给子转换

### 步骤3：创建主作业
1. 创建作业：`jobs/main_job.kjb`
2. 定义参数：`GLOBAL_PARAM`
3. 添加子作业步骤
4. 将GLOBAL_PARAM传递给子作业
5. 子作业再传递给子转换

### 步骤4：参数传递链
```
主作业参数 (GLOBAL_PARAM)
    ↓
子作业参数 (MAIN_PARAM = ${GLOBAL_PARAM})
    ↓
子转换参数 (PROCESS_TYPE = ${MAIN_PARAM})
```

## 知识点
- 多层级参数传递
- 作业调用作业
- 作业调用转换
- 参数作用域
- 参数继承

# 综合案例：参数化ETL流程

## 案例描述
创建一个完全参数化的ETL流程，所有配置都通过参数控制。

## 数据文件
- 输入：根据参数动态选择
- 输出：根据参数动态生成

## 需求
1. 所有文件路径通过参数配置
2. 所有过滤条件通过参数配置
3. 所有输出格式通过参数配置
4. 支持多种运行模式（开发/测试/生产）

## 实现步骤

### 步骤1：定义完整参数列表
- `ENV` - 环境（dev/test/prod）
- `INPUT_DIR` - 输入目录
- `OUTPUT_DIR` - 输出目录
- `INPUT_FILE` - 输入文件名
- `OUTPUT_FILE` - 输出文件名
- `MIN_SALARY` - 最低薪资
- `MAX_SALARY` - 最高薪资
- `DEPT_FILTER` - 部门过滤
- `DATE_FROM` - 开始日期
- `DATE_TO` - 结束日期
- `LOG_LEVEL` - 日志级别

### 步骤2：根据环境设置默认值
- 开发环境：使用测试数据，详细日志
- 测试环境：使用完整数据，标准日志
- 生产环境：使用生产数据，错误日志

### 步骤3：创建参数配置文件
创建 `config/dev.properties`:
```
INPUT_DIR=data/input
OUTPUT_DIR=data/output
MIN_SALARY=5000
MAX_SALARY=10000
```

### 步骤4：使用参数文件
1. 在作业开始时加载参数文件
2. 使用"设置变量"步骤读取配置文件
3. 将配置值设置为变量

## 知识点
- 参数化设计
- 环境配置
- 配置文件使用
- 变量管理
- 最佳实践
