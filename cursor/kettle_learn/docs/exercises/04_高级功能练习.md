# 练习11：JavaScript脚本

## 目标
学习如何使用JavaScript脚本进行复杂的数据处理。

## 数据文件
- 输入：`data/input/employees.csv`
- 输出：`data/output/employees_scripted.csv`

## 步骤
1. CSV文件输入（读取employees.csv）
2. 添加"JavaScript代码"步骤
   - 编写脚本计算绩效等级：
   ```javascript
   var performance_level;
   if (salary >= 9000) {
       performance_level = "优秀";
   } else if (salary >= 7000) {
       performance_level = "良好";
   } else {
       performance_level = "一般";
   }
   ```
3. CSV文件输出
4. 连接并运行

## 知识点
- JavaScript脚本
- 条件判断
- 字段赋值
- 脚本调试

# 练习12：条件分支

## 目标
学习如何使用Switch/Case进行条件分支处理。

## 数据文件
- 输入：`data/input/employees.csv`
- 输出：多个文件（按部门分类）

## 步骤
1. CSV文件输入（读取employees.csv）
2. 添加"Switch/Case"步骤
   - 字段：department
   - 值：
     - 技术部 -> 输出到tech_dept.csv
     - 销售部 -> 输出到sales_dept.csv
     - 人事部 -> 输出到hr_dept.csv
     - 财务部 -> 输出到finance_dept.csv
     - 默认 -> 输出到other_dept.csv
3. 为每个分支添加CSV文件输出
4. 连接并运行

## 知识点
- 条件分支
- Switch/Case
- 多路输出
- 默认分支

# 练习13：错误处理

## 目标
学习如何处理数据转换中的错误。

## 数据文件
- 输入：`data/input/employees.csv`（可以添加一些错误数据）
- 输出：`data/output/employees_valid.csv`
- 错误输出：`data/output/employees_error.csv`

## 步骤
1. CSV文件输入（读取employees.csv）
2. 添加"数据验证"步骤
   - 验证规则：
     - salary > 0
     - email包含@符号
     - name不为空
3. 添加"中止"步骤（处理验证失败的数据）
   - 输出错误信息到文件
4. CSV文件输出（处理验证通过的数据）
5. 连接并运行

## 知识点
- 数据验证
- 错误处理
- 异常捕获
- 错误日志

# 练习14：作业调度

## 目标
学习如何创建作业并设置调度。

## 步骤
1. 创建新作业（New Job）
2. 添加"START"步骤
3. 添加"转换"步骤
   - 选择之前创建的转换文件
4. 添加"成功"步骤
5. 添加"失败"步骤
6. 添加"邮件"步骤（可选）
   - 配置邮件通知
7. 连接步骤：
   - START -> 转换
   - 转换 -> 成功（成功时）
   - 转换 -> 失败（失败时）
8. 添加"定时"步骤（可选）
   - 设置执行时间
9. 保存并运行作业

## 知识点
- 作业创建
- 步骤连接
- 成功/失败处理
- 邮件通知
- 定时调度
