# 练习1：CSV文件读取和输出

## 目标
学习如何使用Kettle读取CSV文件并将数据输出到另一个CSV文件。

## 数据文件
- 输入：`data/input/employees.csv`
- 输出：`data/output/employees_output.csv`

## 步骤
1. 创建新转换（New Transformation）
2. 添加"CSV文件输入"步骤
   - 文件名：选择 `data/input/employees.csv`
   - 分隔符：逗号（,）
   - 编码：UTF-8
   - 获取字段：点击"获取字段"按钮
3. 添加"CSV文件输出"步骤
   - 文件名：`data/output/employees_output.csv`
   - 分隔符：逗号（,）
   - 编码：UTF-8
   - 包含表头：是
4. 连接两个步骤（按住Shift键拖拽）
5. 运行转换

## 知识点
- CSV文件输入配置
- CSV文件输出配置
- 步骤之间的连接
- 字段映射

# 练习2：数据库连接和查询

## 目标
学习如何连接数据库并执行查询。

## 前置条件
需要准备一个数据库（MySQL/PostgreSQL/SQLite等）

## 步骤
1. 创建数据库连接
   - 工具 -> 数据库连接
   - 新建连接，配置数据库信息
2. 创建新转换
3. 添加"表输入"步骤
   - 选择数据库连接
   - 输入SQL查询语句
4. 添加"表输出"步骤
   - 选择目标数据库和表
   - 配置字段映射
5. 连接并运行

## SQL示例
```sql
SELECT * FROM employees WHERE salary > 7000
```

## 知识点
- 数据库连接配置
- SQL查询
- 表输出配置

# 练习3：字段选择和重命名

## 目标
学习如何选择特定字段并重命名。

## 数据文件
- 输入：`data/input/employees.csv`
- 输出：`data/output/employees_selected.csv`

## 步骤
1. CSV文件输入（读取employees.csv）
2. 添加"选择/过滤值"步骤
   - 选择字段：id, name, department, salary
   - 重命名字段：
     - id -> employee_id
     - name -> employee_name
     - department -> dept
     - salary -> monthly_salary
3. CSV文件输出
4. 连接并运行

## 知识点
- 字段选择
- 字段重命名
- 字段类型转换
