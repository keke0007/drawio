# Kettle 快速开始指南

## 🚀 第一步：安装Kettle

1. 下载Pentaho Data Integration (Kettle)
   - 官网：https://sourceforge.net/projects/pentaho/
   - 或访问：https://www.hitachivantara.com/en-us/products/data-ops-software/data-integration-analytics.html

2. 解压到本地目录（如：C:\kettle）

3. 运行Spoon.bat（Windows）启动图形界面

## 📋 第二步：了解界面

### 主要区域
- **左侧面板**：步骤和作业项列表
- **中间画布**：设计转换/作业的工作区
- **右侧面板**：属性配置区
- **底部面板**：执行日志和预览数据

### 核心概念
- **转换（Transformation）**：数据转换流程，文件扩展名.ktr
- **作业（Job）**：工作流，可以包含多个转换，文件扩展名.kjb
- **步骤（Step）**：转换中的基本处理单元
- **跳（Hop）**：步骤之间的连接线

## 🎯 第三步：完成第一个练习

### 练习1：CSV文件读取和输出

1. **创建新转换**
   - 文件 -> 新建 -> 转换
   - 或按 Ctrl+N

2. **添加CSV文件输入步骤**
   - 在左侧面板找到"输入" -> "CSV文件输入"
   - 拖拽到画布中
   - 双击打开配置：
     - 文件名：浏览选择 `data/input/employees.csv`
     - 分隔符：`,`
     - 编码：`UTF-8`
     - 点击"获取字段"按钮
     - 点击"确定"

3. **添加CSV文件输出步骤**
   - 在左侧面板找到"输出" -> "CSV文件输出"
   - 拖拽到画布中
   - 双击打开配置：
     - 文件名：`data/output/employees_output.csv`
     - 分隔符：`,`
     - 编码：`UTF-8`
     - 勾选"包含表头"
     - 点击"确定"

4. **连接步骤**
   - 按住Shift键
   - 从"CSV文件输入"拖拽到"CSV文件输出"
   - 释放鼠标，形成连接线

5. **运行转换**
   - 点击工具栏的绿色运行按钮（▶）
   - 或按F9
   - 查看执行日志，确认成功

6. **查看结果**
   - 打开 `data/output/employees_output.csv`
   - 验证数据是否正确

## 📚 第四步：按顺序学习

按照以下顺序完成练习：

1. ✅ 完成练习1-3（基础练习）
2. ✅ 完成练习4-7（数据转换）
3. ✅ 完成练习8-10（数据连接）
4. ✅ 完成练习11-14（高级功能）
5. ✅ 完成综合案例

详细步骤请查看 `docs/exercises/` 目录下的文档。

## 💡 常用快捷键

- `Ctrl+N` - 新建转换
- `Ctrl+O` - 打开文件
- `Ctrl+S` - 保存
- `F9` - 运行转换/作业
- `F5` - 预览数据
- `Ctrl+Z` - 撤销
- `Ctrl+Y` - 重做
- `Delete` - 删除选中步骤

## 🔍 调试技巧

1. **预览数据**
   - 右键点击步骤 -> 预览数据
   - 可以查看该步骤的输出结果

2. **查看日志**
   - 底部面板的"执行结果"标签
   - 查看错误信息和警告

3. **逐步执行**
   - 可以只运行部分步骤
   - 使用"空操作"步骤作为断点

## ❓ 遇到问题？

1. 检查数据文件路径是否正确
2. 检查字段名称是否匹配
3. 查看执行日志中的错误信息
4. 使用预览数据功能逐步排查
